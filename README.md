# 💇 Agenda Salão

Sistema simples de agendamento online para salões de beleza.

## ✨ Funcionalidades

* Cadastro de cliente
* Informar telefone
* Escolha de serviço
* Seleção de data
* Seleção de horário
* Registro do agendamento

## 🛠 Tecnologias

* HTML
* CSS
* JavaScript

## 🎯 Objetivo

Facilitar o processo de marcação de horários em salões de beleza através de uma interface simples e intuitiva.
